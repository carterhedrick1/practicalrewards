Before You Cancel a Companion Fare Booking, Check the Code

Published September 21, 2026

By Carter

Already booked with an Alaska/Atmos cash companion-fare code? Check the code’s expiration before canceling—the ticket and the code are separate things to sort out.

The companion-specific rule matters

Alaska’s official discount-code page has a paragraph specifically for companion fares. It says:

  • If the code is unexpired when the ticket is canceled, it is redeposited with its original expiration date.
  • If the code has expired when the ticket is canceled, it is forfeited.
  • Tickets booked with companion-fare codes can be changed within applicable fare rules.

The same page also contains generic discount-code forfeiture language. Read the companion-specific paragraph for this distinction; stopping at the generic wording misses it.

Official rule: https://www.alaskaair.com/shared/tips/AboutDiscountCodes.aspx

Same expiration, no fresh clock

Here is a hypothetical calendar example, assuming that rule applies to your code. Its original expiration is October 31:

  • Cancel on October 15: the unexpired code is redeposited with the same October 31 expiration.
  • Cancel on November 5: the code is expired and is forfeited.

Cancellation does not buy more time. The original deadline comes back with the code.

The catch: getting the code back is not getting your money back

The companion-code paragraph does not promise a ticket refund or specify redeposit timing. Any refund or ticket credit depends on the applicable fare rules—check those separately.

It allows ticket changes within applicable fare rules, but does not promise a cost-free change or explain what happens to the code in every change scenario. Do not treat that sentence as a guarantee that canceling and rebooking is safe.

Before touching the reservation

Check your own code’s expiration and the booked ticket’s change and cancellation terms. If either is unclear, contact the airline before canceling and ask what each option means for both the code and the money paid.

If you are comparing replacement trips, the free Practical Rewards calculator can compare costs using your inputs: https://practicalrewards.com/calculators/alaska-companion-fare.html. It cannot validate your code, determine cancellation treatment, or confirm availability.

Practical verdict

Use this check whenever plans change on an existing cash companion-fare booking. If the code has expired, skip cancel-and-rebook as a default move—ask about changing the ticket under its fare rules first. If it is still valid, remember that redeposit preserves the original expiration, not a fresh deadline.
